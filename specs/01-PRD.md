# PRD · AI 英语口语陪练工具

> 产品需求文档（Product Requirements Document）。回答"**为谁、做什么、为什么、做到什么程度算成功**"。
> 本文是所有设计与实现的源头。AI 在实现功能时，必须能追溯到本文的某条需求。

---

## 1. 产品概述

| 项 | 内容 |
|----|------|
| 产品名 | AI 英语口语陪练（Speak Coach） |
| 一句话定位 | 一个有耐心、懂教学、能记住你的 AI 外教，在真实场景中陪你开口说英语并给出可量化反馈 |
| 目标用户 | 有一定英语基础但缺乏真实开口环境、想提升口语的学习者 |
| 核心价值 | 随时可练的真实场景对话 + 不打断的智能纠错 + 看得见的成长反馈 |
| 项目背景 | 黑客松题目一 |

---

## 2. 用户画像与核心痛点

| 用户 | 痛点 |
|------|------|
| 求职者小李 | 要英文面试，但没人陪练，紧张到说不出话 |
| 留学生小王 | 日常点餐/看医生等场景听不懂、说不对 |
| 职场人小张 | 要参加英文会议，缺乏表达训练和反馈 |

**共同痛点**：① 没有真实对话场景 ② 不知道自己错在哪 ③ 看不到进步、缺乏动力。

## 3. 用户故事（User Stories）

> 格式：作为 \<角色\>，我想要 \<功能\>，以便 \<价值\>。每个故事带验收标准（AC）。

### US-01 选择练习场景
> 作为学习者，我想从预设场景（面试/点餐/会议等）中选择一个，以便针对性练习。

**验收标准 AC：**
- AC1：首页展示 ≥ 3 个场景卡片（面试、点餐、会议）。
- AC2：每个场景可选难度（初级/中级/高级）。
- AC3：选择后进入对话页，AI 以对应角色开场白主动发起对话。

### US-02 实时语音对话
> 作为学习者，我想用语音和 AI 自然对话，以便模拟真实交流。

**验收标准 AC：**
- AC1：点击/按住即可说话，支持自动检测说话结束（VAD）。
- AC2：界面实时显示我说的话的字幕（流式）。
- AC3：从我说完到 AI 开始发声，延迟 ≤ 1.5 秒（首包）。
- AC4：AI 回复有语音播放 + 文字字幕。
- AC5：AI 保持角色人设（面试官严肃、店员热情）和对话目标。

### US-03 发音评测
> 作为学习者，我想知道我的发音哪里不准，以便改进。

**验收标准 AC：**
- AC1：每句话给出发音总分（0-100）。
- AC2：标出读得差的单词/音素。
- AC3：提供 4 个维度评分：准确度、流利度、完整度、语调。

### US-04 智能纠错（不打断）
> 作为学习者，我想在不打断对话的前提下被纠错，以便保持流畅又能改进。

**验收标准 AC：**
- AC1：对话过程中**不**实时弹窗打断纠错。
- AC2：仅当出现"沟通阻断级"错误时，AI 以自然重述（Recast）隐性纠正。
- AC3：所有错误被静默记录，用于课后复盘。
- AC4：纠错区分"语法错误"（必须改）与"表达升级"（更地道说法）。

### US-05 课后总结报告
> 作为学习者，我想在练习后看到一份总结报告，以便了解表现和进步。

**验收标准 AC：**
- AC1：展示本次对话全文 + 逐句批注（错误/建议）。
- AC2：5 维能力雷达图（发音、流利、语法、词汇、任务完成度）。
- AC3：高频错误 TOP3。
- AC4：地道表达升级列表（"你说的" → "更地道的"）。
- AC5（P1）：与历史会话对比的成长曲线。

---

## 4. 功能优先级（MoSCoW）

| 优先级 | 功能 |
|--------|------|
| Must（P0） | US-01（1个场景）、US-02 实时对话、US-04 课后集中纠错、US-05 报告核心 |
| Should（P1） | US-03 发音评测、多场景多难度、隐性重述 |
| Could（P2） | 成长曲线、角色音色定制、多人会议场景 |
| Won't（本期不做） | 社交/排行榜、付费体系、移动端原生 App |

---

## 5. 关键非功能需求（NFR）

| 类别 | 要求 |
|------|------|
| 性能 | 语音对话首包延迟 ≤ 1.5s；端到端单轮 ≤ 3s |
| 可用性 | 网络异常时有降级与提示，不白屏 |
| 兼容性 | 支持 Chrome / Edge 最新版（麦克风权限） |
| 可演示性 | 提供可离线兜底的 Demo 路径（防现场网络问题） |

---

## 6. 成功指标（Demo 视角）

- 评委能亲自完成一轮完整对话（开口 → 对话 → 看报告）。
- 对话延迟体感"像真人"。
- 课后报告的数据可视化有"哇时刻"。
- 能清晰讲出差异化：不打断的纠错哲学 + 可量化成长。

---

## 7. 范围边界（避免 AI 跑偏）

**本期明确不做**：用户注册登录体系（用本地匿名 session）、支付、社交、内容运营后台、移动端原生应用。

> AI 实现时若发现需求超出本范围，**必须停下来确认**，不得自行扩展。
